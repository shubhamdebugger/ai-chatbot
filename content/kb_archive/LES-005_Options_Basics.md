Question forms:
- CE PE kya hota hai?
- option kya hai
- premium kya hota hai
- expiry kya hai
- what is a call option

Answer:
An option is a contract whose price (the premium) moves with the underlying, such as Nifty.
CE (call) premium usually rises when the underlying rises; PE (put) premium usually rises when it falls.
Options are traded in lots of a fixed quantity and expire on a set date; time value falls as expiry comes near.
Options can lose value fast — buyers can lose the whole premium. Risk must be defined before entry.

Never say:
- Which strike or option to buy.
